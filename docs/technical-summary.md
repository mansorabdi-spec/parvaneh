# سامانه هوشمند صدور مجوز پارکینگ و باربری شهری

## مستندات فنی کلی - شهرداری ارومیه

---

### ۱. معرفی سامانه

سامانه پاروانه (Parvaneh) یک پلتفرم جامع و یکپارچه الکترونیک جهت **مدیریت و صدور مجوزهای شهری** شامل مجوز پارکینگ، ورود خودروهای باربر به مرکز شهر، حفاری معابر و فعالیت‌های مشابه می‌باشد. این سامانه با هدف **حذف کاغذ**، **کاهش مراجعات حضوری**، **افزایش شفافیت** و **سریع‌سازی فرآیند صدور** طراحی و پیاده‌سازی شده است.

---

### ۲. معماری فنی

| لایه | فناوری | توضیحات |
|------|---------|---------|
| **فرانت‌اند** | React.js 18 + Vite | رابط کاربری واکنش‌گرا (Responsive) |
| **استایل‌دهی** | Tailwind CSS | طراحی مدرن و بهینه |
| **بک‌اند** | Node.js + Express.js | API سرعتمند و مقیاس‌پذیر |
| **پایگاه داده** | Microsoft SQL Server | ذخیره‌سازی رابطه‌ای امن |
| **احراز هویت** | JWT Token | امنیت بالا با عمر توکن قابل تنظیم |
| **خروجی PDF** | jsPDF + PDFKit | تولید خودکار مجوزهای چاپی |

### ۴. قابلیت‌های کلیدی

- ✅ **منطقه‌بندی رنگی** (سبز / زرد / قرمز) برای مدیریت ترافیک
- ✅ **محدودیت زمانی هوشمند** با بررسی خودکار تداخل
- ✅ **تایید دسته‌جمعی** درخواست‌ها توسط پلیس
- ✅ **عودت خودکار وجه** به کیف پول در صورت رد درخواست
- ✅ **کیف پول الکترونیک** داخلی برای پرداخت‌های آسان
- ✅ **گزارش‌های آماری** با فیلتر تاریخ، شرکت و نوع مجوز
- ✅ **تقویم شمسی** و پشتیبانی کامل فارسی/RTL
